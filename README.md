# Music-320-C-Project

This is a synthesizer project for the MUSIC 320E course. It is built using the JUCE framework and Faust for the digital signal processing (DSP) code.

## Dependencies

To build and run this project, you will need:

- The [JUCE framework](https://juce.com/get-juce)
- A C++ compiler (like Visual Studio, Xcode, or GCC)

## Building the Project

1.  Open the `FaustSynthStarter.jucer` file in the Projucer.
2.  Select your target IDE (e.g., Visual Studio 2022, Xcode).
3.  Click "Save and Open in IDE".
4.  Build and run the project from your IDE.

## Project Structure

- `Source/`: Contains the C++ source code for the synthesizer plugin.
- `faust/`: Contains the Faust DSP code.
- `FaustSynthStarter.jucer`: The JUCE project file.
- `JuceLibraryCode/`: Autogenerated JUCE code.
- `Builds/`: Contains the build files for different platforms.
